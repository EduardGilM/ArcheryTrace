# Logo ArcheryTrace

Generado con ImageGen integrado, modo generación nueva (`logo-brand`). Original: [logo-generated.png](logo-generated.png). Se realizaron únicamente conversiones de tamaño para mobile/icon-192.png, mobile/icon-512.png, android/res/drawable/ic.png. La notificación Android usa una figura monocroma vectorial separada.

## Prompt final

Use case: logo-brand. Create one production Android app icon for ArcheryTrace, a precision archery training app. Single centered distinctive geometric mark: an elegant arrowhead forming an A integrated with a restrained partial target ring, suggesting precision and recorded motion. Flat vector-like solid orange #ff8220 on a uniform deep charcoal #0e0e12 square background. Strong silhouette, crisp clean edges, readable at 48px. Mark contained within central 60 percent of square for adaptive icon safe area. Premium minimal sports instrument aesthetic matching a dark orange-accent UI. No text, no letters rendered as typography, no gradients, shadows, mockups, device frames, extra symbols or watermark. Square 1024x1024 raster asset.

La imagen devuelta es de 1254 × 1254 píxeles; se conserva el original. Las versiones instalables están redimensionadas a las dimensiones del proyecto.
